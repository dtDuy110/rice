# PROJECT OVERVIEW

Build a premium rice ecommerce platform.

Tech stack:
- React + Vite
- TailwindCSS
- React Router
- Axios
- NodeJS
- ExpressJS
- MongoDB
- JWT authentication

# UI REQUIREMENTS

Follow the UI designs inside /design folder exactly.

Design style:
- Premium ecommerce
- Organic agriculture branding
- Modern SaaS admin dashboard
- Smooth spacing
- Reusable components

Color palette:
- Green #2F5D50
- Gold #D4A437
- Beige #F5F1E8

# FRONTEND STRUCTURE

Use:
- component-based architecture
- reusable cards/buttons/modals
- responsive layouts
- clean folder structure

Pages:
- Home
- Product Listing
- Product Detail
- Cart
- Login/Register
- Admin Dashboard
- Product CRUD

# BACKEND REQUIREMENTS

Create REST APIs:
- auth
- products
- orders
- users

Use MVC architecture.

# CODING RULES

- Write clean code
- Avoid duplicated components
- Use Tailwind utility classes
- Keep components modular
- Use async/await
- Proper error handling
- Mobile responsive
